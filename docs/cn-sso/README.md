本区面向准备采购、建设或审计集成的企业客户。除了说明登录怎么接，更重点评价外部系统实际可调用的 **API、SDK、事件、权限、配额、测试与企业交付能力**。SAML/OAuth/OIDC 是否标准只是评价的一部分。

## 登录方向仍要分清

“企业 SSO 集成”有两个方向，同一平台在两个方向上的能力往往不同：

| 方向 | 平台扮演的角色 | 典型诉求 |
|---|---|---|
| 用企业已有账号登录平台 | 平台作为 SP/依赖方 | 企业已有 IdP，希望员工统一登录平台 |
| 用平台账号登录外部系统 | 平台作为身份源 | 用飞书、钉钉、企业微信或微信账号登录 OA、网站、设备 |

各平台分别支持哪些方向和协议，见各自对接页。但企业采购不能只看“能否登录”：还要确认通讯录/内容 API、SDK、事件、权限审批、配额和交付条款。尤其微信个人账号不能替代企业员工身份；音乐平台的账号互通也不能当作通用企业 SSO。
